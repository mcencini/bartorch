API object index#

Every documented object, by module. The pages of the API reference list the same objects in tables; this page generates the page of each.

bartorch#

fft

Fourier transform along axes, centred by default.

ifft

Inverse Fourier transform along axes: fft() with inverse=True.

fftshift

Move the zero frequency to the middle along axes, or back with inverse.

fftmod

Multiply by the alternating phase that centres an uncentred transform, along axes.

nufft

Non-uniform Fourier transform of an image to samples along traj.

nufft_adjoint

Adjoint of nufft(): samples along traj back to an image.

fwt

Forward multi-level discrete wavelet transform along axes.

iwt

Wavelet synthesis along axes: coefficients from fwt() back to samples.

soft_thresh

Soft thresholding, x * max(1 - lamda / |x|, 0).

hard_thresh

Hard thresholding: keep x where |x| > lamda, zero elsewhere.

resize

Crop or zero-pad input to oshape.

flip

Reverse input along axes.

circshift

Cyclic shift along axes: element i moves to (i + shift) % n, as torch.roll.

conv

Cyclic convolution of input with kernel along axes, of the input's shape.

window

Multiply by a Hamming window along each of axes, or a Hann window.

median_filter

Median over each window of length consecutive elements along axis.

moving_average

Mean over each window of length consecutive elements along axis.

normalize

Divide by the l2 norm over axes, or the l1 norm, per index of the other axes.

mip

Maximum or minimum intensity projection over axes, which are kept as size one.

unwrap

Unwrap the real part along axis: remove the jumps a period of 2 * bound puts in it.

casorati

Casorati matrix of the overlapping blocks of input.

rss

Root of the sum of squared magnitudes over axes.

interpolate

Sample input at the voxel positions coord along axes.

maps_to_kernels

Coil sensitivities as k-space kernels: the centre of each map's unitary spectrum.

kernels_to_maps

The maps a kernel bank stands for: zero-padded to spatial and transformed back.

BartError

A BART command or operator failed; the message is BART's.

set_num_threads

Set the number of threads BART, its FFT and FINUFFT's host transforms use.

set_copy_inputs

Whether a command works on a private copy of each input, which is the default.

set_debug_level

Set BART's verbosity: 0 errors, 1 warnings, 2 info, 3 and up debug.

get_debug_level

cuda_available

Whether BART can run on a CUDA device: built with CUDA, and a device present.

set_cuda_streams

Set the number of CUDA streams BART runs on, 1 to 8.

use_cuda_memcache

Whether BART keeps freed device memory for its own reuse.

bart_version

Version string of the embedded BART.

build_info

How the library was built: BART version, compiler, nested-function mode, CUDA.

backend_sources

The library serving each BLAS and LAPACK routine, and the FFT.

bartorch.linop#

CartesianSense

Cartesian SENSE encoding operator.

NoncartesianSense

Non-Cartesian SENSE encoding operator.

WaveSense

Wave-CAIPI encoding operator.

FieldCorrected

Off-resonance-corrected encoding operator, by time segmentation.

LinearOperator

A linear map between two C-order shapes, with an adjoint.

Identity

The identity on shape, BART's linop_identity.

Zero

The operator that sends everything to zero, BART's linop_null.

Diagonal

Pointwise multiplication by diag, broadcast over the axes where it is one.

ComponentDiagonal

A diagonal on the real part and another on the imaginary part.

Conj

Complex conjugation, BART's linop_zconj.

Real

The real part, BART's linop_zreal.

FFT

BART's unitary Fourier transform along axes, centred by default.

NUFFT

Non-uniform FFT from images to samples along a trajectory.

MultiplySum

Multiply by a tensor and sum over the axes absent from the codomain.

Matrix

Multiplication by a matrix along one axis, BART's linop_matrix.

Convolve

Convolution with a fixed kernel, BART's linop_conv.

Gradient

Finite differences along axes, stacked on a new leading axis.

concatenate

Apply every operator to the same input and lay the results end to end.

stack

Apply every operator to the same input and put the results on a new axis.

hstack

Split the input between the operators and add up what they return.

block_diag

Give each operator its own part of the input and its own part of the output.

block

A block matrix of operators.

Reshape

Read the same elements under another shape, BART's linop_reshape.

Transpose

Swap two axes, BART's linop_transpose.

Permute

Rearrange the axes, BART's linop_permute.

Flip

Reverse axes, BART's linop_flip.

Roll

Shift along one axis, BART's linop_shift.

Pad

Make each axis longer, BART's linop_padding.

Resize

Crop or zero-fill about the centre of each axis, BART's resize -c.

Extract

Take the block of oshape that starts at start, BART's linop_extract.

Hankel

A sliding window along axis, BART's linop_hankelization.

Sum

Sum over axes, BART's linop_sum.

ScaledSum

Sum over axes, divided by the square root of how many were summed.

Mean

Average over axes, BART's linop_avg.

Repeat

Repeat along axes up to shape, BART's linop_repmat.

bartorch.nlop#

NonlinearOperator

Nonlinear operator between tensor shapes, with a derivative and its adjoint.

TorchOperator

A nonlinear operator from a differentiable torch function.

NonlinearSense

Joint image and coil-sensitivity forward model, BART's noir.

CartesianSense

Cartesian joint image and coil-sensitivity forward model.

NoncartesianSense

Non-Cartesian joint image and coil-sensitivity forward model.

CoilSense

Product of an image and unknown coil sensitivities, through any encoding.

SignalModel

A TorchSim signal model as a BART nonlinear operator.

InversionRecovery

T1 from an inversion-recovery series.

MultiEcho

T2 or T2* from a multi-echo readout.

Bloch

Any TorchSim sequence as a model operator, through Bloch simulation.

Multiply

The pointwise product of two inputs, broadcast where either is one.

Divide

a / b, elementwise, of two inputs of one shape.

Weighted

a * x + b * z of two inputs of one shape.

Constant

An operator of no inputs that returns value.

Exp

exp(x), elementwise.

Log

log(x), elementwise.

Sqrt

sqrt(x), elementwise.

Power

x ** exponent, elementwise.

Add

x + value, elementwise.

Inverse

1 / x, elementwise.

Abs

|x|, elementwise, as a complex tensor.

SmoothAbs

sqrt(|x|^2 + eps), elementwise.

Phase

x / |x|, elementwise: BART's zphsr, built out of its two pieces.

SumOfSquares

sum(|x|^2) along axes, BART's zss.

RootSumOfSquares

sqrt(sum(|x|^2)) along axes.

IRGNM

Iteratively regularized Gauss-Newton for F(x) = y, looping IRGNMBlock.

IRGNMBlock

One step of iteratively regularized Gauss-Newton, noir's Gauss-Newton step.

irgnm

Solve F(x) = y by iteratively regularized Gauss-Newton.

bartorch.optim#

CG

Conjugate gradients for a least-squares problem with quadratic penalties.

IST

Iterative soft thresholding, looping ISTBlock.

FISTA

Fast iterative soft thresholding, looping FISTABlock.

ADMM

Alternating direction method of multipliers, looping ADMMBlock.

PRIDU

Primal-dual iteration, looping PRIDUBlock.

NIHT

Normalized iterative hard thresholding.

POCS

Projection onto convex sets, looping POCSBlock.

Tikhonov

A quadratic penalty weight * ||operator x - bias||^2.

maxeigen

Power-iteration estimate of the largest eigenvalue of the normal operator.

POCSBlock

One sweep of the projections, italgos.c's pocs.

cg

Solve a linear least-squares problem by conjugate gradients.

ist

Solve a regularized least-squares problem by iterative soft thresholding.

fista

Solve a regularized least-squares problem by fast iterative soft thresholding.

admm

Solve a regularized least-squares problem by alternating direction multipliers.

pridu

Solve a regularized least-squares problem by a primal-dual iteration.

niht

Solve a sparsity-constrained least-squares problem by normalized hard thresholding.

pocs

Sweep a list of projections, optim.POCS(projections)(y, x0=x0).

ISTBlock

One step of iterative soft thresholding, italgos.c's ist.

FISTABlock

One step of fast iterative soft thresholding, italgos.c's fista.

ADMMBlock

One step of the alternating direction method of multipliers, admm.c's admm.

PRIDUBlock

One step of BART's primal-dual iteration, italgos.c's chambolle_pock.

FixedPoint

block iterated to its fixed point: a deep-equilibrium model.

data_scaling

Normalization factor for the data of a reconstruction.

bartorch.priors#

L1

l1 norm of the image.

Wavelet

l1 norm of the wavelet transform over axes.

LocallyLowRank

Nuclear norm of overlapping blocks over axes, i.e. locally low rank.

L2

Squared l2 norm of the image, i.e. Tikhonov regularization.

NonNegative

Projection onto images whose real and imaginary parts are non-negative.

TotalVariation

l1 norm of the finite differences over axes, i.e. total variation.

FourierL1

l1 norm of the Fourier transform over axes.

Laplace

Laplacian penalty over axes.

ImaginaryL1

l1 norm of the image's imaginary part.

ImaginaryL2

Squared l2 norm of the image's imaginary part.

TotalGeneralizedVariation

Total generalized variation over axes.

InfimalConvolutionTV

Infimal convolution of total variation over axes.

InfimalConvolutionTGV

Infimal convolution of total generalized variation over axes.

WaveletNIHT

Keep the count largest wavelet coefficients over axes.

ImageNIHT

Keep the count largest image entries.

Regularizer

Regularization functional with a proximal operator built by BART.

ImplicitPrior

A denoiser substituted for a bartorch.priors regularizer.

frozen

term with its proximal step detached, for a differentiated solve.

rof

Total-variation (Rudin-Osher-Fatemi) denoising along axes.

tgv

Second-order total generalized variation denoising along axes.

nlmeans

Non-local means filter along axes.

bartorch.learning#

Denoiser

Adapter applying a real-valued image network to a complex image.

Unrolled

Unrolled network formed by applying an iteration block iterations times.

as_real

Real and imaginary parts of input stacked along a new leading axis.

as_complex

Complex tensor formed from a leading axis of real and imaginary parts.

bartorch.apps#

pics

Parallel-imaging compressed-sensing reconstruction.

pocsense

POCSENSE reconstruction: the measured samples, the coils, and sparsity.

mobafit

Fit a signal model to reconstructed contrast images, voxel by voxel.

bartorch.tools#

phantom

An analytical phantom, as an image or as its k-space.

coils

Compute coil sensitivitity maps in x-space or k-space.

fakeksp

Recreate k-space from image and sensitivities.

noise

Add noise with selected variance to input.

traj

A k-space trajectory, in grid units.

grid

Compute sampling grid for x-space / k-space (and time).

pattern

Compute sampling pattern from kspace

poisson

Computes Poisson-disc sampling pattern.

upat

Create a sampling pattern.

raga

Generate file with RAGA indices for given approximated tiny golden ratio angle/raga increment and full frame spokes.

psf

Calculate point-spread-function (PSF) of given trajectory.

wavepsf

Generate a wave PSF in hybrid space.

estdims

Estimate image dimension from non-Cartesian trajectory.

estdelay

Estimate gradient delays from radial data.

trajcor

Correct delays for a given trajectory.

rmfreq

Remove angle-dependent frequency

bin

Binning

ssa

Perform SSA-FARY or Singular Spectrum Analysis.

ecalib

Coil sensitivities by ESPIRiT.

caldir

Coil sensitivities from the centre of k-space directly.

calmat

Compute calibration matrix.

ecaltwo

Second part of ESPIRiT calibration.

walsh

Estimate coil sensitivities using walsh method (use with ecaltwo).

ncalib

Estimate coil sensitivities using ENLIVE calibration.

cc

Performs coil compression.

ccapply

Apply coil compression forward/inverse operation.

rovir

Compute coil compression matrix using ROVir.

whiten

Apply multi-channel noise pre-whitening on <input> using noise data <ndata>.

estvar

Estimate the noise variance assuming white Gaussian noise.

estscaling

Estimate scaling from k-space center.

phasepole

Detect and sample phase poles.

pics

Parallel-imaging compressed-sensing reconstruction.

nlinv

Nonlinear inversion: the image and the sensitivities together.

rtnlinv

Jointly estimate a time-series of images and sensitivities with nonlinear inversion using {iter} iteration steps.

moba

Model-based nonlinear inverse reconstruction

mobafit

Pixel-wise fitting of physical signal models.

looklocker

Compute T1 map from M_0, M_ss, and R_1*.

itsense

A simplified implementation of iterative sense reconstruction with l2-regularization.

sqpics

Parallel-imaging compressed-sensing reconstruction.

pocsense

Perform POCSENSE reconstruction.

sake

Use SAKE algorithm to recover a full k-space from undersampled data using low-rank matrix completion.

lrmatrix

Perform (multi-scale) low rank matrix completion

homodyne

Perform homodyne reconstruction along dimension dim.

grog

GROG calibration and gridding of radial data.

wave

Perform a wave-caipi reconstruction.

wshfl

Perform a wave-shuffling reconstruction.

fovshift

Shift the field of view of k-space data by a linear phase.

affine_transform

Resample input on an affinely mapped grid: out(u) = input(matrix @ [u, 1]).

warp

Pull input through a displacement field: out[p] = input(p + displacement[p]).

register_affine

Affine transform that maps reference onto moved, by mutual information.

register_nonrigid

Displacement field from reference into moved, by greedy SyN or TV-L1 optical flow.

estimate_shift

Sub-voxel shift that moves b onto a, from the phase of their cross-spectrum.

nrmse

Normalized root mean square error ‖input - reference‖ / ‖reference‖.

mse

Mean squared error mean |input - reference|² over every element .

psnr

Peak signal-to-noise ratio of the magnitudes in decibels, averaged over images .

ssim

Mean structural similarity of the magnitudes .

roi_stat

Statistic of input over the region roi.
