Optimization#

bartorch.optim provides BART’s iterative algorithms for linear inverse problems. A solver is configured by its constructor and called as solver(y, A, x0=None), with y the data and A a LinearOperator; it reproduces BART’s iteration, including its step sizes, penalty updates and stopping rules. An iteration block is one step of the same iteration as a torch.nn.Module. A leading axis of y beyond the codomain of A is a batch of independent problems. Inverse problems and their solvers states the problems and algorithms, and Differentiation through reconstruction the backward pass of each solver.

Functional interface#

Each function constructs the corresponding solver and calls it: optim.fista(y, A, term, maxiter=30) is optim.FISTA(term, maxiter=30)(y, A).

Iteration blocks#

state = block.start(y, A, x0) initializes a run, state = block(state, A) takes one step and block.output(state, A) returns the image. Step sizes and penalty weights are torch.nn.Parameter objects, frozen until requires_grad_() is called on them.

Object

Description

One fast iterative soft-thresholding step
