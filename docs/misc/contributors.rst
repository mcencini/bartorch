Contributors and citation
=========================

bartorch is developed by its repository contributors, building on the work of
the BART developer team and the PyTorch and numerical-library communities.
See the `contribution history
<https://github.com/mcencini/bartpy/graphs/contributors>`_ for current credits.
For an offline list, run ``git shortlog -sne HEAD``; inspect BART's submodule
history separately. See :doc:`../guides/developer/contributing` to participate.

Citing methods and software
---------------------------

Report the bartorch version/commit and pinned BART revision, and cite the
algorithms actually used (for example ESPIRiT or Wave-Shuffling). BART maintains
`citation and reproducibility resources
<https://mrirecon.codeberg.page/publications.html>`_. Links to the papers behind
advanced gallery plans are in :doc:`../gallery/research`.

No bartorch paper or archival DOI is declared by this checkout, so this page
does not invent one. A reproducibility statement should also record trajectory
units, array order, calibration, sampling, normalization, solver settings,
backend versions and device configuration.
