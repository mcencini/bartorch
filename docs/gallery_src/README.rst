Example Gallery
===============

Learn the workflow in order: prepackaged tools, encoding building blocks,
an app assembled in Python, and reconstruction applications. Each script is
standalone and downloadable as Python or a notebook. Examples use synthetic
CPU data and do not download images or pretrained weights.

The default documentation build renders source without running it. To reproduce
plots and numerical checks, follow :doc:`/guides/developer/documentation`.
``optional_`` examples additionally require the dependencies stated on the page.
These teaching examples are not measured-data reproductions of cited papers.

For the operator inventory and advanced methods, see :doc:`/gallery/encoding`,
:doc:`/gallery/research`, and :doc:`/gallery/learning_resources`.
