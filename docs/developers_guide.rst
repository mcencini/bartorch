Developer's Guide
=================

Layout
------

``csrc/``
    The C sources that turn BART into a library: the C ABI in
    ``include/bartorch.h``, the in-memory array registry, the command runner,
    the FFT over pocketfft, the BLAS and LAPACK shims, and the operator layer.

``bart/``
    The BART submodule, compiled unchanged.  Every translation unit is built
    except ``main.c``, ``bbox.c``, ``ismrmrd.c`` and ``misc/memcfl.c``, which
    ``csrc/memcfl.c`` replaces so that arrays BART creates are allocated by the
    host.

``src/bartorch/``
    The Python package.  ``_lib.py`` loads the library through ctypes,
    ``core/graph.py`` runs tools on tensors, ``ops.py`` wraps operators, and
    ``tools/`` holds one function per BART command, generated by
    ``build_tools/gen_tools.py`` from the BART sources.

Build
-----

.. code-block:: bash

   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
   cmake --build build -j
   BARTORCH_LIBRARY=$PWD/build/libbartorch.so PYTHONPATH=src pytest tests/

``pip install -e .`` does the same through scikit-build-core and places the
library inside the package.

BART is written against GNU C and the library is a clang build: its nested
functions become Blocks, with the vendored runtime on platforms that lack
one, so the library never needs an executable stack.  GCC would need one,
because BART's static-chain workaround reads a trampoline layout GCC emits
only for non-PIC executables.

Symbols
-------

The library exports the ``bartorch_*`` ABI and nothing else.  BART's own
symbols are hidden, so the library coexists with any other BLAS, FFT or
BART in the process.  A BART routine is replaced by leaving its translation
unit out of the build and compiling a unit with the same signatures; no
linker tricks are involved.

Regenerating the tool wrappers
------------------------------

.. code-block:: bash

   python build_tools/gen_tools.py

Run it after moving the submodule to a new BART commit.

Tests
-----

A test pins BART against a reference computed outside BART: numpy's FFT, an
explicit discrete Fourier sum, a closed-form signal, an adjoint identity.
Anything numerical is checked that way rather than against BART itself.
