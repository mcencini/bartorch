# Code of conduct

## Community expectations

Make collaboration welcoming to people with different backgrounds, experience
and identities.  Be respectful, support technical disagreement with evidence,
accept corrections, and credit others' contributions.  These expectations apply
to issues, pull requests, reviews and project discussions.

Harassment, discriminatory language, threats, sexualized attention, personal
attacks and publishing another person's private information are unacceptable.
Direct criticism at work and behaviour, and respect requests to stop.

## Reporting and governance

This page proposes community expectations for a developing project.  The
repository does not yet designate a confidential reporting contact or a formal
enforcement process; maintainers should establish those before presenting this
as an adopted, enforceable policy.  Do not post sensitive incident details in a
public issue; use a maintainer's published private contact or the hosting
platform's reporting mechanism.
